# Русскоязычные Telegram-каналы про Claude Code, вайбкодинг и ИИ-агентов

Каталог живых каналов по теме разработки с ИИ. Число подписчиков и дата последнего поста обновляются автоматически раз в сутки.

Каналов в каталоге: 42, чатов: 2. Без постов 30 и более дней: 0. Данные обновлены: 2026-11-27 (UTC).

## Для кого

Для разработчиков и тех, кто пишет код вместе с ИИ: чтобы быстро найти, где по-русски разбирают Claude Code, кодовых агентов, вайбкодинг и построение систем вокруг языковых моделей. Каталог не оценивает каналы и не ранжирует их по качеству, внутри раздела порядок задаёт число подписчиков.

## Критерии включения

Одни и те же правила для всех каналов, включая канал автора каталога.

1. Язык постов: русский.
2. Тема: Claude Code и кодовые агенты, вайбкодинг, ИИ-агенты и LLM-инженерия, ИИ в процессах разработки или новости ИИ с уклоном в разработку.
3. Живой канал: есть пост за последние 30 дней на момент добавления. Лента `t.me/s/<канал>` должна быть открыта, иначе дату поста не проверить.
4. Это канал с авторским содержанием, а не сетка или агрегатор: не перепечатка чужих лент, не автоматическая выдача, не набор каналов одного владельца под общим брендом.
5. Это не чистая воронка в платный продукт: у канала должны быть собственные полезные посты, а не только анонсы курсов, ботов и закрытых клубов.
6. Боты не принимаются. Открытые чаты и группы по той же теме идут отдельным разделом «Чаты»: вместо даты поста там число участников, вход должен быть открыт по ссылке `t.me/<чат>`.

Если канал после добавления пропустил 30 дней, он остаётся в таблице с пометкой ⏸. Канал, который не пишет несколько месяцев или исчез, удаляется.

## Как предложить канал

- Откройте [issue «Предложить канал»](../../issues/new?template=add-channel.yml) и заполните форму.
- Или отправьте pull request: добавьте блок `[[channel]]` в `data/channels.toml` (хэндл без `@`, название, раздел, одна строка «о чём»). Таблицы в README пересоберёт скрипт, руками их не правят.

Каналы проверяются по критериям выше. Рекламные и платные размещения не принимаются.

## Как это работает

Список лежит в `data/channels.toml`. Скрипт берёт с `https://t.me/s/<канал>` число подписчиков и дату последнего поста, сохраняет их в `data/stats.json` и пересобирает этот README из `templates/README.md.tmpl`. GitHub Actions запускает обновление раз в сутки и коммитит изменения. Если канал не ответил, остаются прежние цифры; если Telegram сообщил, что канала нет, скрипт пишет об этом в лог.

Локальный запуск:

```bash
uv sync
uv run ru-ai-channels update     # обновить данные и README
uv run ru-ai-channels render     # пересобрать README без сети
uv run ru-ai-channels check      # проверить, что README соответствует данным
uv run ru-ai-channels probe имя_канала  # посмотреть, что вернёт Telegram для канала
```

Если `t.me` недоступен напрямую, задайте прокси: `RU_AI_CHANNELS_PROXY=socks5h://127.0.0.1:10808`. По умолчанию прокси не используется.

Разработка: `uv run ruff check . && uv run ruff format --check . && uv run mypy && uv run pytest`.
